# See in Wiki

A Final Fantasy XIV Dalamud plugin that adds a **"See in Wiki"** option to the right-click context menu of any in-game item.

Clicking it opens the item's page on [FFXIV Console Games Wiki](https://ffxiv.consolegameswiki.com/wiki/FF14_Wiki) in your default web browser.

---

## ✨ Features

- **Right-Click Anywhere**: Works in Inventory, Armory Chest, Retainer bags, Chocobo Saddlebag, chat item links, vendor shops, recipes, and the Market Board.
- **English Name Matching**: Automatically resolves the item's English name so wiki pages load correctly, even if your game client is in another language.
- **Glamour Support**: Includes a "See in Wiki (Glamour)" option when right-clicking glamoured gear.
- **Chat Command**: `/seeinwiki <item name>` to search manually, or `/seeinwiki` to toggle chat feedback.

---

## 📦 Installation (Custom Repo)

1. In-game, open Dalamud by typing `/xlplugins` in chat.
2. Click **Settings** (gear icon) → **Experimental**.
3. Under **Custom Plugin Repositories**, paste:
   ```
   https://raw.githubusercontent.com/Nep940/SeeInWiki/main/repo.json
   ```
4. Click **+**, then click **Save and Close**.
5. Go to the plugin list, find **See in Wiki**, and click **Install**.
